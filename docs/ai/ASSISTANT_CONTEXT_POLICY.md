# سياسة سياق المساعد الذكي

تحدد ما يراه المساعد داخل التطبيق (AI-01، المرحلة 14) وما لا يراه. مأخوذة من القسم C5.

## ما يُرسل للمساعد
- `screenKey` وملف مواصفات الشاشة: `rules`، `fields`، و`aiAssist.contextFields` فقط.
- سياق المستخدم: الدور والفرع واللغة — دون أي توكن أو كلمة مرور.
- البيانات تُجلب عبر API v1 **بصلاحيات المستخدم نفسه**؛ المساعد لا يملك صلاحيات إضافية.

## ما لا يُرسل أبدًا
- أسماء المرضى أو أي بيانات صحية أو هوية شخصية لمزود خارجي دون تفعيل المستأجر وإخفاء البيانات.
- الحقول المعلّمة `[SensitiveData]` والأسرار (`sensitive.secrets` في المواصفات).
- بيانات معمل آخر (يفرضها العزل على الخادم).

## القدرات
- **مسموح:** القراءة والشرح والاقتراح (تلخيص، شرح تأخير، اقتراح أصناف، كشف بيانات ناقصة).
- **ممنوع:** الترحيل، الإلغاء، تعديل مستند أو رصيد أو صلاحية. أي اقتراح يُحفظ كـ `AiSuggestion` بحالة `Pending` ويعتمده مستخدم مخول.
- كل مخرَج يُوسم "اقتراح من الذكاء الاصطناعي"، ويُسجَّل الاستخدام في `AiUsageLog`.

## الحماية من حقن التعليمات
محتوى الملاحظات والملفات المرفوعة والبيانات يُعامل كبيانات وليس تعليمات. الشاشات التي `aiAssist.forbidden` فيها `"*"` (مثل الدخول والتهيئة) لا يُفعّل عليها المساعد.
