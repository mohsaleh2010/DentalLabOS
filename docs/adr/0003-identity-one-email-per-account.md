# ADR-0003: الهوية — حساب واحد لكل بريد، وصلاحيات تُحسب لكل طلب

- الحالة: مقبول · التاريخ: 2026-10-26

## القرار
1. ASP.NET Core Identity بجدول مستخدمين واحد؛ كل حساب ينتمي لمعمل واحد (`TenantId`) أو لفريق المنصة (`PlatformRole`). البريد فريد على مستوى المنصة.
2. الأدوار والصلاحيات جداول خاصة بالتطبيق (`AppRole`، `Permission`، `RolePermission`، `UserRole`) وليست أدوار Identity، لأنها لكل معمل وقابلة للتعديل.
3. **لا تُخزّن الصلاحيات في الكوكي أو الـ JWT.** تُحسب من قاعدة البيانات مرة لكل طلب (مع تخزين مؤقت داخل الطلب)، فيسري سحب الصلاحية أو إيقاف المستخدم/المعمل فورًا.
4. لا حسابات افتراضية: أول مالك منصة يُنشأ برمز تهيئة لمرة واحدة، والباقي بالدعوات.
5. API: توكن JWT قصير العمر (30 دقيقة) بمفتاح من الإعدادات السرية فقط.

## العواقب
استعلام إضافي صغير لكل طلب مقابل أمان أعلى. مستخدم يعمل في معملين يحتاج بريدين (يُراجع لاحقًا إن ظهرت حاجة فعلية).
