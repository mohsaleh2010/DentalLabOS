# ADR-0005: الترجمة من ملفات JSON مشتركة

- الحالة: مقبول · التاريخ: 2026-10-26

## القرار
`IStringLocalizer` مخصص يقرأ `SharedUI/Resources/{ar,en}.json` (مفاتيح مسطحة مثل `Admin.Users.Invite`). العربية افتراضية، والاتجاه RTL/LTR يتبع اللغة. المصدر للتعديل هو `tools/i18n/strings.py` ويُولد الملفين.

## المبررات
ملف واحد للويب والـ API والجوال لاحقًا، وسهل التدقيق. اختبارات تمنع المفاتيح الناقصة أو الاختلاف بين اللغتين أو اختلاف المتغيرات `{0}`.
