# ADR-0006: الاستضافة

- الحالة: **مقترح — بانتظار قرار صاحب المشروع** · التاريخ: 2026-10-26

## المقترح
- Azure App Service (Linux) للويب والـ API + Azure SQL Database + Azure Key Vault للأسرار + Blob Storage للمرفقات، أو ما يعادلها لدى مزود آخر.
- نسخ احتياطي تلقائي مع Point-in-time restore؛ الهدف المبدئي RPO ≤ 15 دقيقة وRTO ≤ 4 ساعات.
- Data Protection keys في تخزين مشترك مُشفّر عند تشغيل أكثر من نسخة.

## مطلوب لحسمه
الميزانية، موقع البيانات (داخل مصر/المنطقة أم لا)، ومتطلبات الامتثال المحلية.
