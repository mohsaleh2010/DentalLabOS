# ADR-0001: Modular monolith على .NET 10

- الحالة: مقبول · التاريخ: 2026-10-26

## السياق
الخطة تتطلب منصة SaaS متعددة الوحدات (إنتاج، مخزون، مالية) بفريق صغير في البداية، مع حاجة لمعاملات متسقة بين الوحدات (مثل صرف مخزون على أمر شغل وترحيل قيده).

## القرار
تطبيق واحد قابل للنشر (Web + Api يشتركان في Application/Infrastructure) بطبقات: Domain ← Application ← Infrastructure ← Web/Api. الوحدات تُفصل بالمجلدات والـ namespaces وحدود واضحة في Application، مع قاعدة بيانات واحدة.

## البدائل
- Microservices: تعقيد تشغيلي ومعاملات موزعة غير مبررة في هذه المرحلة.
- طبقة واحدة بلا فصل: يصعب اختبارها وفصلها لاحقًا.

## العواقب
اختبارات المعمارية تمنع اعتماد Domain/Application على البنية التحتية. يمكن فصل وحدة لاحقًا إن ظهرت حاجة حقيقية.
